# For Glory

A console-based, turn-based RPG developed in C++
as a computer science course project.

<img width="627" height="498" alt="image" src="https://github.com/user-attachments/assets/33f7e15e-4123-4411-9c61-3431ddd091d2" />


## Features

- Three playable classes: Warrior, Wizard, and Rogue
- Turn-based combat against randomized opponents
- Class-specific abilities and resource management
- Experience points and character progression
- Character saving and loading
- Healing mini-game

## Programming Concepts

- Object-oriented programming
- Inheritance and polymorphism
- Abstract classes and virtual functions
- File I/O
- Dynamic memory management
- Random number generation

## Build and Run

```bash
g++ -std=c++17 *.cpp -o ForGlory
./ForGlory
```
